# 메카넘 STM32 주행보드 (Uno + Moebius 쉴드 대체)

[docs/stm32-자세보드-목표.md](../../docs/stm32-자세보드-목표.md) 2단계(G2 엔코더 4채널 + G4 전원 도메인 분리)를 하는 보드.
펌웨어 = [firmware/mecanum_stm32/](../../firmware/mecanum_stm32/) (mecanum_stable v2.1 프로토콜 그대로 → 젯슨 코드 수정 없음).

- `gen_pcb.py` = **회로도 겸 배치**. 부품·넷·자리를 여기서 정하고 돌리면 `mecanum_stm32.kicad_pcb`가 다시 나온다.
  `"C:/Program Files/KiCad/9.0/bin/python.exe" gen_pcb.py` (겹침 0이어야 끝). `.kicad_sch`는 없다.
- 지금 상태: **배선 완료** — 미연결 0 · DRC 오류 0(실크 경고 69만). 선분 1,951 · 비아 201, 양면 GND 동박.
  거버는 아직 안 뽑았다. `placement.png` = 윗면 3D 렌더.
- 다시 만들기 (순서 중요 — `gen_pcb.py`가 저장하며 `.kicad_pro` 넷클래스를 덮어쓰고, `route.py`가 다시 넣는다):
  ```
  K="C:/Program Files/KiCad/9.0/bin/python.exe"
  "$K" gen_pcb.py                 # 배치(빈 판)
  "$K" route.py prep              # 넷클래스 + mecanum_stm32.dsn
  java -jar freerouting-2.5.0.jar -de mecanum_stm32.dsn -do mecanum_stm32.ses --router.autorouter.max_passes=60 --gui.enabled=false
  "$K" route.py finish            # .ses 가져오기 → 전원선 굵히기 → GND 동박 → 저장
  ```
  배치를 안 바꿨으면 Freerouting 없이 저장소의 `mecanum_stm32.ses`로 `gen_pcb.py` → `route.py finish`만 하면 같은 판이 나온다.
  ⚠ KiCad 9.0.4의 `pcbnew.ExportSpecctraDSN`은 헤드리스에서 멈춰서 DSN/SES 변환을 `route.py`에 직접 짰다.

## 무엇을 왜 골랐나

| 자리 | 부품 | 왜 |
|---|---|---|
| MCU | **STM32F405RGT6** (LQFP64 0.5mm) | 엔코더 모드 타이머 4개(TIM2·3·4·5)를 다 쓰고도 PWM용 TIM8(4ch)·TIM9·TIM12가 남는다. F103은 TIM1~4뿐이라 엔코더 4개를 쓰면 PWM이 없고, F411은 TIM8이 없어 PWM이 TIM1(=USART1 PA9/PA10)과 겹친다. 엔코더 핀은 전부 5V 톨러런트(FT) |
| 모터 드라이버 ×4 | **DRV8874PWPR** (HTSSOP-16) | VM 37V(레일 12.6V의 ×2.9 — 목표 G4 "≥1.5배"), 6A 피크, **IPROPI 전류 감지 → ADC**, **nFAULT**, 내부 전류 제한(VREF). 지금 HR8833은 10.8V 정격에 12V를 물려 7/29에 탔다 |
| 젯슨 링크 | **CH340C + ADuM1201** | CH340C는 USB 전원(VBUS)으로, ADuM1201이 UART 두 가닥만 건넌다 → **젯슨 GND와 모터 GND가 끊긴다**(USB 끊김 `-71`의 원인 = 접지 루프). 칩이 CH340이라 젯슨에선 똑같이 `/dev/ttyUSB0`(1a86:7523). DTR을 안 물려서 **포트를 열어도 리셋되지 않는다**(Uno는 리셋됐다) |
| 전원 | AO4407A 역접속 보호 → **SMBJ15A**(역기전력 TVS) + 470µF → VM / **SS34 + 470µF 홀드업** → **TPS542025**(5V 고정 벅, 4.5~30V) → AMS1117-3.3 | 모터 기동으로 VM이 처져도 로직은 다이오드 뒤 홀드업으로 버틴다(지금 쉴드는 XL1509가 같이 무너져 BOD 리셋). 5V는 엔코더 전원(VCC50)도 겸한다 |
| 엔코더 | 1k 직렬 + 10k 풀업(3V3) → 타이머 엔코더 모드 | 인터럽트로 세지 않는다(펄스 손실 0, G2). 오픈컬렉터/푸시풀 둘 다 받는다 |
| 커넥터 | JST PH 6핀 ×4, 쉴드와 같은 순서 `M− · GND · ENC_B · ENC_A · 5V · M+` | 모터 선을 그대로 옮겨 꽂게 |
| USB | **Mini-B**(Würth 65100516121, 0.8mm 피치 5핀 + 큰 고정탭) | USB-C는 0.5mm 피치라 손땜이 어려워 바꿨다(CC 저항도 필요 없다). 완전 스루홀이 필요하면 Tensility 54-00023(세로형) |
| 기타 | SWD 헤더, RESET/BOOT0 버튼, I²C 헤더(MPU6050 이전용), SPI IMU 헤더, LED 3개 | 첫 굽기는 SWD 또는 BOOT0. 이후엔 젯슨에서 `U` 명령 → `stm32flash` |

판 = **90×64mm, 2층**. 고정구멍 4개는 **Uno와 같은 자리**(왼쪽 아래 기준)라 지금 스탠드오프에 앉는다.
Uno 크기(68.6×53.3)로는 부품 면적이 판의 67%라 2층 배선이 안 나와서 키웠다(지금 43%).

## ⚠ 만들기 전에 확인할 것

1. **모터에 엔코더가 정말 있나, 커넥터가 PH 2.0mm인가** — 쉴드 회로도상 6핀이지만 실물 확인 전([목표 문서 §0.1](../../docs/stm32-자세보드-목표.md)).
   2.54mm(XH)면 J10~J13 풋프린트만 바꾸면 된다.
2. ~~DRV8874 PMODE·IMODE~~ → **데이터시트(SLVSF66A, 42쪽)로 확인함**: PMODE=High → PWM 모드(표 2, nSLEEP가 올라갈 때 래치 —
   nSLEEP 풀다운이라 순서 OK), IN1=PWM·IN2=0 → 정방향/코스트(표 4, Uno와 같은 동작), IMODE=GND → 고정 오프타임 초핑 +
   과전류 **자동 재시도**(표 6), A_IPROPI 450µA/A.
3. **케이스 트레이에 90×64가 들어가나** — 안 되면 `W, H`를 줄이고 4층으로 간다.
4. **HTSSOP 방열 패드** — 인두로는 안 붙는다. 열풍기/리플로우, 또는 방열 비아로 뒤에서 땜.
5. **자동배선 결과를 사람 눈으로 한 번** — 모터 전류 경로(VM→드라이버→커넥터), 크리스털 주변, 절연 경계
   (GNDU 동박은 USB 칸에만, GND와 1.5mm 간격). 고정구멍 둘레 Ø6.5mm는 동박 금지(나사머리·스탠드오프가 GNDU를 로봇 GND에 잇지 않게).
   배선 굵기: 핀에 들어가는 굵기로 배선한 뒤 `route.py widen()`이 간격이 되는 구간만 0.8/0.6mm로 키웠다(핀 근처는 가늘다 — 걱정되면 2oz 동박).
