펌웨어 = [firmware/mecanum_stm32/](../../firmware/mecanum_stm32/) (mecanum_stable v2.1 프로토콜 그대로 → 젯슨 코드 수정 없음).

  거버 = [`gerber/`](gerber/)(2026-11-09 재생성, 같은 층·드릴 옵션). `placement.png` = 윗면 3D 렌더. 케이스 v2의 100×70 칸·Uno 구멍 그대로.
  **11/09에 바뀐 것과 이유**(검토 보고 → 결정):
  · 배치를 절대 mm로 다시 — 예전엔 Uno 비율로 늘린 좌표 + 30mm 나선 정착이라 U12 차지펌프 캡이 34mm, VCAP1 17mm, 크리스털 13mm 떨어져 있었다.
    IC마다 디커플링·타이밍 부품을 핀 기준 상대 좌표로 묶어 고정하고, 정착은 3mm 이내·고정 부품 불가, **배치 뒤 거리 검사(3mm)가 실패하면 종료코드 1**.
    예외: 드라이버 VM 벌크 C43/C47/C51/C55(10µF)는 핀 11에서 ≈4.1mm — 100nF(C42 등)가 1.9mm에 있고 차지펌프 캡 셋과 출력선이 3mm 안을 다 쓴다.
  · 전원: 예전 VM 0.19mm·VBAT_P 0.3mm 병목(정지 시 9.2A) → **F.Cu 동박 면**(VBAT_IN/VBAT_R/VBAT_P/VM: 위·아래 가장자리 띠 + 오른쪽 기둥 + 드라이버마다 탭).
    전원 넷은 Freerouting이 배선하지 않는다 — 그 넷 패드를 전부 면 안에 두었다(R9·R11·R66·D3·C15·D1·R1 자리 이동). 모터 출력은 gen_pcb가 1.0mm로 미리 깐다.
  · B.Cu는 GND 동박이지만 신호 2층 배선이라 **통짜는 아니다**(B.Cu 신호선 ≈1.9m, GND 채움 ≈3,950mm² ≈ GND 칸의 60%, 7조각 — 모두 비아로 이어짐).
  · DFM: DRV8874 방열 비아 0.2mm×48 → **0.3/0.6mm×12**(비아 없는 풋프린트 + 스크립트가 넣음). 설계규칙(.kicad_pro): 선 0.127·드릴 0.3·비아 0.6·간격 0.13.
  · 절연: U5를 회전 0으로(1~4번=USB 칸) — 예전엔 90°라 GNDU·GND 동박이 0.2mm까지 붙어 있었다. Freerouting에 1.5mm 해자(양면 금지)를 주고, `check`가 USB 넷↔나머지 동박 거리를 잰다.
  · 회로: 소프트 스타트·R1 22k·AMS1117 탄탈·E-stop PTC·코일 제너·ADC 100nF·VDDA 2.2µF·15pF·15µH·출력 22µF×3·Cin 100nF·USBLC6(부품 표는 아래).
- 다시 만들기 (순서 중요 — `gen_pcb.py`가 저장하며 `.kicad_pro` 넷클래스를 덮어쓰고, `route.py`가 다시 넣는다):
  ```
  K="C:/Program Files/KiCad/9.0/bin/python.exe"
  "$K" gen_pcb.py                 # 배치(빈 판)
  FR="java -jar freerouting-2.5.0.jar --router.autorouter.max_passes=60 --router.optimizer.enabled=false --gui.enabled=false"
  "$K" route.py prep              # 넷클래스·설계규칙 + mecanum_stm32.dsn (1단계: 전원 면 = 무른 plane)
  $FR -de mecanum_stm32.dsn -do stage1.ses
  "$K" route.py prep2 stage1.ses  # 2단계: 전원 면 = F.Cu 금지 구역, 면을 침범한 1단계 배선만 빼고 씨앗으로
  $FR -de mecanum_stm32.dsn -do mecanum_stm32.ses
  #   ⚠ optimizer를 켜 두면 최적화 단계에서 멈춰 .ses가 안 써진다(2026-11-02, 3회)
  #   ⚠ 1단계만 쓰면 Freerouting이 plane을 '나중에 다시 채울 동박'으로 보고 다른 넷을 그 위로 지나가게 해 전원 면이 끊긴다.
  #     처음부터 금지 구역으로 주면 배선이 발산한다(미배선 30~170을 오감) → 두 단계(11/09)
  "$K" route.py finish            # .ses 가져오기 → 가는 조각·곁가지 굵히기 → 전원 면(F.Cu) + GND 동박(양면) → 저장
  "$K" route.py check             # 선 ≥0.127 · 드릴 ≥0.3 · 절연 1.5mm · 디커플링 3mm · 전원 면 최소 폭
  kicad-cli pcb drc --severity-error --exit-code-violations mecanum_stm32.kicad_pcb
  ```
  `gen_pcb.py`는 겹침·절연 칸·**디커플링 거리(IC 핀 패드 ↔ 부품 패드 가장자리 ≤3mm)** 중 하나라도 어기면 종료코드 1로 멈춘다.
  배치를 안 바꿨으면 Freerouting 없이 저장소의 `mecanum_stm32.ses`(2단계 결과)로 `gen_pcb.py` → `route.py finish`만 하면 같은 판이 나온다.
  ⚠ KiCad 9.0.4의 `pcbnew.ExportSpecctraDSN`은 헤드리스에서 멈춰서 DSN/SES 변환을 `route.py`에 직접 짰다.

## ⚠ 만들기 전에 확인할 것

1. **모터에 엔코더가 정말 있나, 커넥터가 PH 2.0mm인가** — 쉴드 회로도상 6핀이지만 실물 확인 전([목표 문서 §0.1](../../docs/stm32-자세보드-목표.md)).
   2.54mm(XH)면 J10~J13 풋프린트만 바꾸면 된다.
2. ~~DRV8874 PMODE·IMODE~~ → **데이터시트(SLVSF66A, 42쪽)로 확인함**: PMODE=High → PWM 모드(표 2, nSLEEP가 올라갈 때 래치 —
   nSLEEP 풀다운이라 순서 OK), IN1=PWM·IN2=0 → 정방향/코스트(표 4, Uno와 같은 동작), IMODE=GND → 고정 오프타임 초핑 +
   과전류 **자동 재시도**(표 6), A_IPROPI 450µA/A.
3. **케이스** — 옛 트레이에선 100×70이 배터리 턱을 15.6mm 넘었다(11/05 계산). [케이스 v2](../case/README.md)는 앞 가운데에 이 판 자리를 뒀다(같은 구멍, 간섭 검사 통과) → 판을 다시 배치하지 않는다.
   제조 한계(11/09 개정): 선 ≥0.127mm, 드릴 ≥0.3mm(DRV8874 방열 비아 0.3/0.6mm × 12개/칩) — 설계규칙(.kicad_pro)이 DRC로 강제한다.
   **주문 메모: 동박 2oz 권장**(전원 면·모터선 저항·온도 절반).
6. **배터리가 24V면**(6S 만충 25.2V) — 바꿀 것: TVS SMBJ15A→SMBJ24A, 470µF 25V→35V, 1206 10µF 25V→50V(C3·C43 등),
   **블리더 R66/R67 0603(100mW)→1206** 또는 2.2k×2(25.2V에서 0603 각 159mW로 정격 초과), **Q1/Q4 → −40V P-FET**(AO4407A −30V는 84% 사용),
   소프트 스타트 C15 1µF→2.2µF(돌입 에너지 0.72J — 램프를 늘려 FET 평균 전력을 맞춘다), R1 22k는 그대로(D1이 Vgs −12V로 묶음).
   ⚠ SMBJ24A는 정격 펄스에서 Vc 38.9V로 DRV8874 권장 37V(절대 40V)를 넘는다 — 6S면 SMBJ 계열로는 맞는 게 없으니 클램프를 다시 고를 것.
   TPS542025(30V)·벌크(35V)·릴레이(28VDC)·분압(36V까지)은 그대로.
7. **선택 사항(이번엔 안 넣음)**: IPROPI에 10nF(데이터시트 허용, 코스트 감쇠라 IPROPI가 PWM으로 끊긴다 — 펌웨어 슬로 감쇠나 동기 샘플링이 우선),

4. **HTSSOP 방열 패드** — 인두로는 안 붙는다. 열풍기/리플로우, 또는 방열 비아로 뒤에서 땜.
