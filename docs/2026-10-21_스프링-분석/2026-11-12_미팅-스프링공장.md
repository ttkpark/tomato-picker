# 포너즈 × 제본 코일 공장 미팅 정리 (2026-11-12)

## 한눈에

- **로봇이 할 일**: 기계가 1.5초마다 내놓는 **2개 세트 둘(하나는 이미 뒤집힘)을 포개 4개 묶음**으로 만들고, **트레이 5칸을 모두 채운다**. 시작은 사진 5, 끝은 사진 11
- **왜 로봇인가**: 지금의 덮는 포장 방식은 충격에 쉽게 흩어진다. 실린더로 밀면 끝에서 "팅" 튕겨 어긋난다. 사람처럼 **사뿐히 내려놓는 힘 조절**이 핵심이고, 링을 잡으면 처지므로 **잡는 방식**도 중요하다
- **범위 밖**: 뒤집기(기계 쪽), 박스 적재·포장과 빈 트레이 투입(사람), 내수용 펄프지 포장(진공으로 못 집음)
- **제어**: 로봇이 **기계 PLC 입력**(ON/OFF 접점)으로 토출 속도 3단계를 고르고, 불량이면 멈춘다. 라인 속도는 로봇에 맞춘다(사람보다 약 3배 느리지만 24시간)
- **조건**: 사내 설비라 KC·EMC 인증 불필요 · 8시간 이상 연속 운전되는 산업용 등급 팔 · 비전 먼저, 오차가 크면 좌표 고정
- **다음**: 포너즈는 바로 개발·시연 공유. 공장은 사이즈별 샘플(9.5 먼저), 변수 정리본, PLC 입력 사양을 준다

## 2. 제품

- 원사로 성형하는 **제본·달력용 트윈 와이어**("달력 구멍에 탁탁 들어가는")
- 규격 **"34공"** — 고리 34개로 보인다(3:1 피치 A4 길이, 약 290mm) · 주력은 **9.5와 11mm 계열**, 더 큰 것도 있다 [33:20] [1:10:05]
- 링을 잡으면 **처진다**. 작은 사이즈는 탄성으로 버티고, 클수록 무게로 더 처진다 [35:11]
- 색상 여러 종(검·흰 등). "다 하게 되면 다 한다" [00:46]

## 3. 공정 (사진 1~11)

1. 기계가 타래에서 **2줄을 병렬로 뽑아 스스로 자른다**
2. 두 줄을 합쳐 **2개가 정확히 포개진 세트**로 만든다 — 피치가 틀어지거나 고리가 엉뚱한 자리에 들어가면 떼기 어렵고 합쳐지지 않는다. 이것이 **최고 속도를 정한다**
3. 세트가 **약 1.5초마다** 작업 테이블에 나온다
4. 지금은 사람이 세트 둘을 모아 **하나를 뒤집고 다른 하나 위에 포개 4개 묶음**을 만든다
5. 묶음을 **트레이 칸(5칸)**에 넣는다. 트레이는 포장 박스 각 층에 끼운다

- 기계 속도 = **피치가 안 틀어지는 최대값**. 사이즈마다 시험해서 정했고, 서보로 더 올릴 수는 있지만 엉뚱한 구멍에 들어갈 위험이 있다 [42:29]
- 작업자는 앉아서 받는다. 기계가 빠르면 못 따라가 멈추고, 그러면 뒤에 쌓인다(견학 중)
- 포개는 방식: 예전 = 뒤집어 합치기(충격에 안 벌어지지만 사용자가 떼기 불편) → 지금 = 위에 덮기(떼기 쉬움, 대신 **실린더로 밀면 흩어질 만큼 약함**) [47:12]
- 인력 두 그룹: ① 옮겨 담기 ② 정리·포장. 로봇이 ①만 맡아도 한 그룹 대체 [1:04:44]
- 지금 5라인 = 5명 [1:06:51]

## 4. 뒤집기

- 기계 쪽에서 **통로를 지나며 뒤집히게** 할 수 있다(스크류 몰드). 구성은 어느 정도 해 두었다 [28:11]
- 대가: 뒤집힌 쪽이 나오는 위치가 **1~2m 옮겨진다**(토출 후 자리 잡는 거리가 길다)
- 공장이 검토한 다른 방법: 밑에 판으로 뒤집기, 레일로 뒤집기, 핑거 실린더 몇 개
- **로봇은 뒤집지 않는다** — 사진 5 상태(하나는 이미 뒤집힘)로 받는다(11/13 확정)

## 5. 10년 전 4개짜리 자동화 (특허 출원·실생산)

- 위에서 2개 + 아래서 뒤집힌 2개가 **기계 안에서 바로 4개 묶음**이 되어 포장됐다 [21:38]
- 장치: 묶음을 잡아 트레이에 담고 → 한 칸씩 이동하며 채우고 → 컨베이어로 앞쪽에 보내 → 5개씩 쌓아 배출 [30:31]
  - 빈 트레이는 뒤쪽 리프트가 올려 보충, 트레이 양끝 빈 곳을 **진공 흡착**으로 들어 컨베이어에 올림
  - 끝 센서가 감지하면 한 칸 이동, 마지막 자리에서 조금 내려가 쌓임
  - 모든 축이 **스테핑 모터**, 그리퍼는 안쪽에 **스펀지 테이프를 붙인 판**(4개가 한꺼번에 잘 잡힘)
- 약 100박스 생산
- 접은 이유: ① 뒤쪽 링 걸기가 앞쪽의 **2배** 걸림(교체 시간 포함) ② 절단기와 포장기가 따로라 약 **2m** 차지 ③ 당시엔 느리다고 봤다 — 지금 보면 느리지 않았다 [31:40] [25:51]
- 2개 세트 기계로 바꾼 뒤 1개씩 나오던 기계보다 **1.8배** 빠르고 정확도·공간도 낫다
- 4개짜리의 끝단부만 가져와 쓰려고 올해 도면을 그리다 바빠서 멈췄다

## 6. 자동화가 막혔던 이유 (공장이 겪은 변수)

- **링 튕김("팅")**: 실린더로 탄창처럼 밀어 넣으면 트레이에 당길 때 충격으로 틀어진다. 홈에 안착해도 끝에서 튕기면 빠졌다 다시 합쳐지며 어긋난다 [34:24]~[34:46]. 트레이 표면이 미끄러워 끝에서 튄다 [1:11:22]
- **사이즈별 처짐 차이** [35:11]
- **피치 정합**: 조금만 삐뚤면 옆 구멍으로 간다 [42:29] [45:39]
- **앞단 일관성**: 처음이 흔들리면 중간·끝은 더 흔들린다. 타래는 독일 기계 것이라 일정하고, 검토 중인 중국산 성형기는 변동이 있을 수 있다. 성형기 직결은 **지금 범위가 아니다**(11/13 팀 판단) — 지금의 타래 방식을 전제로 한다 [36:51] [44:19]
- 변수는 대부분 파악했고, 중간 공정 방식에 따라 생기거나 사라진다 → **정리해서 전달하기로**
- 얇은 트레이가 가끔 두 장 겹쳐 오는 건 **감수**한다 [1:10:25]

## 7. 로봇팔에 바라는 것

- 핵심은 **놓을 때의 사뿐함**. 잡은 뒤 이송은 빨라도 되고 내려놓을 때만 사뿐히 → 구간별 속도 [48:19] [56:29]
- **처짐 없이 잡기**: 규격 폭(34공)에 맞춘 양쪽 받침으로 들면 처지지 않는다(차장 제안). 하중이 분산되지 않는 잡을 자리는 길이마다 달라서 **샘플**이 필요하다 [33:20] [51:47]
- **집었다는 확인 신호**를 원한다(엔코더 등, 방법은 포너즈가 알려 주기로) [59:44]
- 불량 확인 수단: 차장은 고가 카메라보다 센서면 된다는 쪽, 동행자는 로봇에 카메라는 반드시 [1:00:18] [1:00:33]
- **8시간 이상 연속 운전**: 50만원대 팔은 과열된다. 산업용은 싼 것도 300만원부터(호이) [58:12]. 동행자: 아주 고가가 아니면 공장이 투자 못 할 건 아니다
- 공장도 알리에서 3축 팔(약 240만원)을 알아봤지만 인지·연산까지 새로 짜야 해 실행 못 했다 [57:17]
- 포너즈는 50만원 팔로 동작까지 구현한 영상을 보여 줬다

## 8. 비전 vs 좌표

- 작업대가 늘 같은 자리라는 보장이 없어 먼저 **스스로 찾아 놓기(비전)**에 도전한다 [1:00:34]
- 피치에 민감한 제품이라 비전 오차로 오류가 많으면 **좌표 고정**(팔·판 위치 고정, 잡는/놓는 위치 설정값)으로 바꾼다

## 9. 제어 연동

- 방향은 **로봇 → 기계 PLC 입력**, 신호는 **ON/OFF 접점**. USB·UART도 물었지만 답은 PLC 접점 [52:35]~[56:04]
- 기계 토출 속도를 **3단계**(느림·중간·현재 최고)로 시험해 정해 두고, 로봇 입력으로 고른다. "속도도 단계별로 해 주시면 편하다"
- 불량을 알아채면 **정지 + 알림 → 사람 조치 → 재개** [54:31]
- 예전엔 사람이 기계 속도에 맞췄지만 이제 **라인 전체가 로봇 속도에 맞춘다**. 느려지는 건 괜찮고, 빨라지면 피치가 어긋난다 [54:15]
- 로봇은 사람보다 **약 3배 느리고**, 대신 **24시간** 돈다 [16:42]

## 10. 범위·포장

- 로봇의 몫은 **힘 조절(옮겨 담기)과 알림**. 박스 적재·포장까지 하면 "배보다 배꼽" → 사람 또는 나중 공정 [1:03:00]
- 트레이: **5칸 = 4개 묶음 5개**, 박스 각 층에 끼움. 트레이 포장은 **수출용**
- **내수 대부분은 펄프지(간지)** → 진공 집게로 못 집어 **이번엔 다루지 않는다**. 트레이 포장분은 간지로 바꿀 수 없다(차장 "무조건 틀에") [1:05:40]~[1:06:35]
- 트레이는 사이즈별로만 다르고 색은 상관없다. **9.5로 먼저 최적화** [1:09:44]
- 포너즈는 앞단까지 보고 싶어 하지만 이번 초점은 끝단
- **성형기 직결(타래 생략)은 범위 밖** — 지금의 타래 방식 그대로를 입력으로 본다(11/13 팀 판단)

## 11. 인증·계약

- 사내 자가 사용 설비라 **KC safety·EMC 인증 대상이 아니다**(담당자 설명, 공장은 인증을 많이 받아 봐서 범위를 안다) [14:52]~[15:30]
- 시험해 보고 안정적이면 **주문 제작**으로 납품
- 비용(동행자): 지원받는 일이 아니라 추가 비용은 있을 수 있지만 **큰 금액은 어렵다**. 서로 돈 받고 하는 입장임을 분명히

## 12. 왜 자동화하나

- 지금 5라인만 보면 사람이 더 빠르고 싸다
- 인건비 상승·구인난·숙련 기간 때문에 **사람이 확장의 병목**이다(100라인이면 100명). 자동화하면 그 병목이 없어진다 [1:06:51]
- 포너즈는 무조건 AI가 아니라 **기존 방식에서 크게 안 벗어나는 선**에서 최선을 먼저 찾는다

## 13. 재견학

- 기계 대부분을 공장이 직접 만들었고 PLC가 있다
- 다른 공정 재고 관리용 **수량 카운팅**을 1차로 만들어 두었다(외주처가 수량을 알려 주지 않아서)
- **생산량 추적** 아이디어: 회전부 사이로 레이저를 쏴 회전 속도를 재고, 1회전당 생산량 × 하루 회전수로 계산. 포너즈 "이건 오히려 당장 할 수 있겠다", 다음에 다시 논의 [1:21:08]

## 14. 차 안 (동행자)

- **가격은 공장에 먼저 말하지 말 것** — 나중 금액 협의가 곤란해진다 [1:25:29]
- 1인 인건비가 연 3천만원 이상이라 1년 치면 투자 가치가 있다
- 설비 업체들은 확실하지 않으면 안 뛰어든다. 이 공장은 **의지가 있다**(전에 하려다 답을 못 찾았다)
- 이 공장 말고도 자동화를 원하는 곳이 많다. 지방 공장은 KTX로 가까운 역까지 가서 만난다
- **챗봇 UI는 별건**: 동행자가 전에 여러 사람에게 보여 준 UI에 대해 짱짱맨님이 "어떤 화면이 왜 필요한지 설명이 필요하다". 지금까지는 특정 질문에 맞춰 만들었는데 일반 질문이 많아 방향을 넓히고, 웹사이트처럼 꾸며 다시 전달하기로 [1:28:20]~[1:32:09]

## 15. 할 일

- **포너즈**: 개발 시작·시연 공유 · 로봇→기계 PLC 접점(속도 3단계·정지) 설계 · 집었는지 확인하는 방법 안내 · 챗봇 UI 보완해 재전달
- **공장**: 사이즈별 샘플(9.5·11 중심)과 트레이 · 변수 정리본 · PLC 입력 사양(3단계 속도 세팅)
- **미정**: 뒤집힌 세트가 나오는 위치(1~2m) · 성공률·사이클 목표 숫자 · 비용 규모
