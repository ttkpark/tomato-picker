# 라인 코스 — 기하·색·교정 기록 (2026-08-09)

바닥 CSI 카메라(IMX219, 전면 우측 바퀴 앞)로 주행 테이프를 읽는다.
검출 구현은 [`tools/line_follow.py`](../../tools/line_follow.py), 서비스는
[`deploy/line-follow.service`](../../deploy/line-follow.service).

## 코스 기하 — 흔한 라인트레이서와 다르다

테이프가 **진행 방향과 나란히** 깔려 있고 로봇이 그 위를 오간다. 그래서 바닥
카메라에는 테이프가 **가로 띠**로 보인다. "검은 세로선을 따라 조향한다"는
통상적 구성이 **아니므로**, 그렇게 착각하고 코드를 고치지 말 것.

```
        [케이지1]      [케이지2]      [케이지3]     ← 무대(흰 단)
    ════════════════════════════════════════════
    ▓                                          ▓   ← 양끝 검은 테이프(코스 끝)
    ────────────── 주행 테이프(밝은 회색) ──────────────
                     ↕ 로봇은 이 위를 좌우로 오간다
```

바닥 카메라 화면에서:

| 화면 요소 | 물리적 의미 | 보정 축 |
|---|---|---|
| 띠의 **세로 위치**(`band_y`) | 무대까지의 거리 | `vx` (전후) |
| 띠의 **기울기**(`angle_deg`) | 로봇 요(yaw) 오차 | `w` (회전) |
| 화면 **가로**(x) | 진행 방향 | `vy` (게걸음) |
| **검은 테이프** | 코스 끝 | 정지 |
| **색 마스킹테이프** | 토마토 스테이션 | 정지 후 팔 시퀀스 |

## 색 분리 — 밝기로는 안 되고 채도로 된다

실측(`floor_raw_now.jpg` 기준):

| 대상 | H | S | V | `score = V - 2S` |
|---|---|---|---|---|
| 주행 테이프(밝은 회색) | 132 | 15.5 | 155.3 | **124** |
| 마루(밝은 원목) | 6.6 | 40.5 | 136.9 | **56** |
| 검은 마커 | 145 | 35.9 | 81.2 | **10** |

**밝기 차이는 겨우 18로 약하다**(테이프 155 vs 마루 137). 대신 테이프는
무채색, 마루는 따뜻한 갈색이라 **채도를 함께 보면 확실히 갈린다.**
그래서 임계는 `score = V - 2S > 90`(`LF_TAPE_SCORE`).

> 예전 방식(회색조 Otsu)은 라인이 없어도 마루 나뭇결을 반으로 갈라
> `offset -563px` 유령 라인을 만들어냈다. 색 정보를 버린 게 원인이었다.

## 장착 후 반드시 할 교정 두 가지

### 1. `LF_TARGET_Y` — 무대까지의 목표 거리

로봇을 **토마토를 딸 수 있는 정확한 거리**에 손으로 놓고:

```bash
python3 -c "import json,io;print(json.loads(io.open('/dev/shm/line_status',encoding='utf-8').read())['band_y'])"
```

그 값을 `/etc/systemd/system/line-follow.service`의
`Environment=LF_TARGET_Y=<값>`에 넣고 `daemon-reload && restart`.
이후 `offset_y_px`가 0이면 정위치다.

### 2. 색 마스킹테이프 = 스테이션

`color_marker.hue`(OpenCV 0~179)와 `name`이 상태에 실려 나온다. 케이지마다
**다른 색**을 쓰면 스테이션 번호를 색으로 구분할 수 있다. 서로 멀리 떨어진
색을 고를 것 — 예: 빨강(0) / 초록(60) / 파랑(115).

채도가 낮은 파스텔은 마루와 안 갈리니 **진한 색**으로. 붙인 뒤
`/dev/shm/line_status`의 `color_marker`가 잡히는지 확인.

## 알려진 오검출

- **검은 전선을 코스 끝으로 오인**했다(2026-08-09 실측, 우하단 케이블).
  지금은 "검은 덩어리가 띠에서 화면 높이의 30% 이내"여야 인정한다
  (`LF_DARK_NEAR_BAND`). 그래도 카메라 시야에 **전선을 두지 않는 게** 최선.
- 초점: IMX219 v2.1은 고정초점이 ~1m 이상이라 바닥을 가까이 보면 흐리다.
  라인 검출에는 오히려 무해하지만(노이즈 감소), 색 마커가 작으면 뭉개진다 —
  **마커를 크게(5cm 이상)** 붙일 것.
