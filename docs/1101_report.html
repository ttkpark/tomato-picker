2회빈손낙하

시작 맞춤이 38px 남은 채 출발 → 줄기가 축 옆으로. 고침: 맞춤을 허용(28px)까지 반복.

3회빈손

추적이 꼭지 잎을 줄기로 착각, 옆으로 18mm 잘못 밂. 고침: 줄기 깊이만 보고 이동량 재기, 옆 바로잡기는 가는 기둥일 때만 10mm까지.

4회물림 6.9낙하

반만 열고 물러날 때 턱이 줄기를 끌고 나옴(사진). 고침: 끝까지 열고 물러나기.

5회압력 없음

사람 확인: 줄기가 손끝보다 안쪽 목에 들어감. 고침: 무는거리 70 → 80mm.

6회물림 6.2남음

끝까지 열고 물러나기로 토마토가 고리에 남음.

7회물림 6.7 · 사람 확인낙하

사람 관찰: 놓기를 시작할 때 모터 힘이 잠깐 빠져 팔이 주저앉음. 고침: 팔을 새로 연결할 때 이미 토크가 켜져 있으면 설정(토크 끄기)을 건너뜀 → 3번 연속 연결해도 자세 변화 0°.

8회물림 6.4낙하

끝까지 연 뒤 뒤로 뺄 때 낙하. 열린 사진에서 줄기가 고정 턱 안쪽에 붙어 있음 → 고정 턱이 끌고 나옴.
