## 2. 결정 전에 남은 것

- **엡손**: 출고일을 날짜로 서면 확답(메일 "재고 즉시" vs 견적서 "8~12주"). 데모 장비 선수령은 가능성만(엡손 협조, 조건 미정).
- **MG400**: 데모 장비 고장 시 책임 범위(지금은 "고객 과실 추정, 손망실 ≈200만" 한 줄) → 명백한 과실 한정으로 문서화.
  AS 동의서(2년 차부터 연 60만원+VAT 유상 유지보수 조항) 날인은 PM 결재.
- **HITBOT**: ARM64 빌드 또는 프로토콜 문서. 없으면 제외.
- **공통**: 트레이에 수직으로만 넣을 수 있는지 손 시험(4축 확정 근거). 그리퍼 본체(PGE-2 기성 vs STS3215 자작) 예산.

## 4. 기술 전제 (요구사항 요약)

- 작업: 25g 코일 2개 세트를 포개 4개 묶음 → 트레이 5칸. 집게 수직 유지·직선 이동만(11/17 영상) → **4축 충분**. 작업 반경 300mm 안.
- 끝단: 그리퍼 약 160g(STS3215 자작) 또는 PGE-2 300g + 코일 25g. MG400 정격 500g, 1832 최대 1kg, T3 정격 1kg.
- 제어: Jetson Orin Nano(리눅스 ARM64)에서 Python. 그리퍼 서보·PLC 접점은 Jetson이 직접(로봇 I/O 안 씀).
  - MG400: TCP/IP 텍스트 명령(포트 29999/30003), Dobot-Arm GitHub TCP-IP-Protocol
  - Epson: RC+(윈도)로 내부 프로그램 1회 작성·전송(대리점이 해 줌) → 운전 중 Jetson이 Modbus/Remote Ethernet로 신호·좌표
  - HITBOT: SDK ARM64 빌드 필요
- 업체에 안 밝힌 것: 예산, 고객사(공장) 이름, 제품(코일). 작업은 "25g 와이어 부품 옮기기"로만.
- 요구사항 원문: `../2026-11-12_요구사항-스프링공장.md`, 코일 형상: `../2026-11-15_coil-gripper-designs.html`
