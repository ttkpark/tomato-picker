대상: 젯슨 Orin Nano `192.168.0.8:8090` 실시간 대시보드 (tomato-vision + tomato-voice 서비스)
근거: 동일 세션에서 촬영한 화면 2장(토마토 미제시 / 토마토 제시)

## 1. 관측 결과

| 항목 | 화면 A (토마토 없음) | 화면 B (토마토 손에 들어 제시) |
|---|---|---|
| 상단 배너 | 공중 토마토: **0개** | 공중 토마토: **1개** |
| 위치 | — | **(736, 439)** |
| 낙과(배너) | 0개 | 0개 |
| 영상 오버레이 | `air tomatoes: 0  fallen: 1` | `air tomatoes: 1  fallen: 0` |
| 박스 | 없음 | 초록 박스 1개, 토마토에 정확히 밀착 |
| ground line | 표시됨(주황 수평선) | 동일 |
| 로그 패널 | Whisper 로딩 → 준비 완료 → 마이크 연결됨, 이후 `(발화 감지…)` → `(인식 실패/무음)` 반복 |

### 잘 되는 것 (합격)
1. **GPU YOLO-World 온디바이스 검출이 실제로 동작.** 실제 토마토를 프레임에 넣자 즉시 1개로 올라가고 박스가 밀착, 빼면 0개로 복귀(HOLD_SEC=3 반영).
2. **공중/낙과 분리 판정과 좌표 출력이 대시보드까지 전달됨** — 픽셀 좌표 (736,439) 표시.
3. **영상·개수 상단 고정 + 로그 최신순** 레이아웃이 의도대로 작동, 브라우저에서 원격 확인 가능.
4. 오검출 없음: 화면 A의 복잡한 배경(모니터·키보드·배선)에서 헛검출 0.

### 문제로 확인된 것
1. **[버그] 배너의 낙과 수치가 영상과 불일치.** 화면 A는 오버레이 `fallen: 1`인데 배너는 `낙과: 0개`.
   원인: [shared_vision.py:65](../src/tomato_picker/voice/shared_vision.py#L65) — 공중 개수(`air`)가 **바뀔 때만** 이벤트를 발행한다.
   공중 개수가 그대로면 낙과 수·위치가 갱신되지 않고 과거 값에 고정된다. 위치도 같은 이유로,
   토마토가 화면에서 움직여도 개수가 안 변하면 좌표가 낡은 채 남는다.
2. **[오검출 성격] 책상 위 토마토 "사진"을 낙과로 셌다.** 화면 A의 fallen:1은 실물이 아니라 인쇄/화면 속 토마토.
   부스 현장에서 포스터·배너·관람객 옷의 토마토 그림이 그대로 계수될 위험.
3. **ground line이 고정 픽셀(y=600).** 카메라가 팔·베이스와 함께 움직이면 공중/낙과 판정이 통째로 틀어진다.
   현재는 "카메라 고정" 전제인데, 주행하는 데모와 전제가 충돌.
4. **좌표가 픽셀뿐.** (736,439)로는 팔이 갈 수 없다. 깊이/스케일이 없어 인식→행동 연결이 끊겨 있음.
5. **음성 인식이 이 세션에서 0건 성공.** 로그가 `(발화 감지…)` → `(인식 실패/무음)`만 4회 반복.
   데모의 첫 관문이 음성이므로 우선순위 높음.

## 2. 기능 개선 제안 (우선순위 순)

### P0 — 부스 데모 신뢰성에 직결
| # | 제안 | 내용 | 예상 공수 |
|---|---|---|---|
| 1 | **상태 발행 조건 수정** | `air` 변화가 아니라 `(air, fallen, positions)` 튜플 변화 또는 최소 0.5s 주기로 발행. 배너·오버레이 불일치 제거. | 10분 |
| 2 | **음성 실패 원인 규명** | 마이크 게인/거리, `MIN_PEAK 0.15` 임계, VAD 구간 길이 로그를 남기고 실기 재현. 실패 시 원문 후보라도 로그에 노출해 진단 가능하게. | 1~2h |
| 3 | **오검출 방어** | 최소 박스 크기·종횡비·채도 필터 추가(사진 속 토마토는 대개 작거나 저채도). 부스에선 실물만 계수. | 1h |

### P1 — 데모 완성도
| # | 제안 | 내용 |
|---|---|---|
| 4 | **좌표를 로봇 좌표로** | 나무 위치가 고정이므로 픽셀→팔 프리셋 매핑 테이블(호모그래피 or 구역 3~4칸)로 충분. "인식 결과가 행동을 고른다"는 서사가 이때 완성됨. |
| 5 | **ground line 자동/교정 모드** | 주행 중엔 판정을 홀드하거나, 시작 시 1회 캘리브레이션 화면 제공. |
| 6 | **대시보드에 상태 뱃지** | 비전 FPS, 모델 로드, 카메라 연결, 시리얼(베이스/팔) 연결을 상단에 색 뱃지로. 현재는 문제가 생겨도 화면상 구분이 안 됨. |
| 7 | **낙과 카운트 별도 강조** | "떨어진 토마토 n개" 자체가 스토리(품질관리)로 쓸 수 있는 지표. 배너 2단 구성. |
