# `3D/` 파츠 — 실기 위치와 실측 치수 (2026-09-26)

기준: 팔 집게가 향하는 쪽(면봉·줄기 잡는 방향) = **전면**.
치수는 STL을 직접 잘라서(단면 폐곡선) 뽑았다 — 도구: STL 단면 스크립트, 오차 ±0.1mm.
**판 부품(TOPLeft/TOPRight)은 모두 XZ 평면에 누워 있고 두께 방향이 +Y**다(Inventor 원본 좌표 그대로).

| 파일 | 실기 위치 | 케이스 설계 대상 |
|---|---|---|
| `BOTTOM` | 차체 아래 — 전원 회로 상자(벅부스트·전류계), 나사 4개로 상판 밑에 체결 | ○ (간섭 확인용) |
| `TOPRight` | 상판 위 **후면** — 젯슨 썰매(레일 사이로 젯슨이 들어감) + 바닥 카메라 집게 | ○ |
| `TOPLeft` | 상판 위 **전면** — 아두이노 지지판 | ○ |
| `upper`, `lower`(`lower1/2`) | 팔에 달린 D405 카메라 마운트 | ✕ |
| `Part1` | (STL 없음, 원형 링+브래킷 — 용도 미확인) | ? |

> ⚠ 2026-09-26 정정: 처음엔 TOPRight=전면으로 적었으나 `전체 외관.pdf` 4쪽("앞쪽이 아두이노 쪽이었다")으로 뒤집음.
> ⚠ BOTTOM 바닥 구멍은 실물이 손으로 다시 뚫려 STL과 조금 다르다(같은 PDF 17쪽) — BOTTOM의 구멍 좌표는 믿지 말 것.

## 줄자·캘리퍼 실측 (`전체 외관.pdf`, 기준점은 사용자 확인 2026-09-26)
길이 방향 = 앞(아두이노)→뒤(젯슨). "나사"는 모두 50×30 체결 패턴의 나사다.

| 값 (mm) | 무엇 (사용자가 밝힌 기준점) |
|---|---|
| **151.9** | 차체 상판(검정 판) 가로 — 버니어 캘리퍼스 |
| **136** | TOPLeft **가장 뒤** 나사 ↔ TOPRight **가장 앞** 나사 (길이 방향) |
| **195.5** | TOPLeft **가장 앞** 나사 ↔ TOPRight **가장 뒤** 나사 (길이 방향) — **차체 길이가 아니다** |
| **121** | BOTTOM **뒷벽** ↔ TOPRight **뒤 끝** (PDF 12쪽 위 사진) |

> ⚠ 자동운전 사이클 595가 195.5를 "차체 상판 세로 확정", 121을 "모터 마운트~ 유효 전폭 확정"으로
> 적었으나 둘 다 틀렸다(위 표가 사용자 확인값). 차체 상판 **길이는 아직 아무도 재지 않았다** — 케이스는
> 나사 구멍 기준이고 바퀴가 폭 바깥에 있어 길이를 몰라도 된다.

## 공용 체결 규격 — 차체 상판 구멍 (확정)
- **M3 Ø3.2, 50 × 30 사각 패턴 두 벌.** TOPLeft·TOPRight가 원본 좌표까지 같다.
- **30 변이 길이 방향, 50 변이 가로 방향**: 195.5 − 136 = 59.5 ≈ 30 + 30 (0.5mm는 줄자 오차).
  TOPRight(가로 150 ≈ 상판 151.9)의 50 변이 판의 가로 축에 있는 것과도 맞는다.
- **두 패턴 중심 간격 = 136 + 30 = 166** (바깥 나사 195.5로 검산: 166 + 30 = 196, 차이 0.5).
- 가로 위치: 상판 가운데 (TOPRight에서 판 중심과 0.5mm 이내).
- TOPRight 안에서 패턴은 앞쪽(팔 쪽) 끝에 붙어 있고, **뒤 나사 줄 → 판 뒤 끝 = 81**.
  → 121 실측과 합치면 **BOTTOM 뒷벽은 TOPRight 뒤 나사 줄보다 40 앞**이다.
- 케이스 좌표(앞벽=0)에서는 앞 나사 줄을 20에 두었다 → 패턴 중심 y = 35 / 201.

## TOPLeft — 아두이노 지지판
- 외곽 **97.0 × 69.75**, 판 두께 **2**(외곽 테 3)
- 차체 체결: 위 50×30 M3 패턴(Ø3.22)
- 아두이노 보스: **7×7 각기둥, 높이 4**(판 위 Y3→7), 구멍 **Ø2.93**(M3 셀프탭)
  - 보스 좌표(X,Z): (−82.74, 27.32) (−82.74, 55.32) (−30.64, 21.32) (−31.74, 70.32)
  - 간격 27.9 / 52.1 / 50.8 = **Arduino Uno R3 공식 구멍 패턴과 일치** (±0.2)
- 케이블 슬롯 **39.9 × 4.2** (Z=18 중심)

## TOPRight — 후면 젯슨 썰매
- 외곽 **150.0 × 120.0**, 판 두께 **2**(외곽 테 3)
- 차체 체결: 위 50×30 M3 패턴(Ø3.22) — TOPLeft와 동일 좌표
- 아래로 튀어나온 **위치 결정 보스 2개**: 11×11, 길이 4 (Y −5→−1), 구멍 Ø3.4
  - X 간격 **111.4** (X −134.52 / −23.12, Z −19.21)
- 위로 선 **레일 2개**: 폭 2.5, 높이 13 (Y 3→16), 길이 94.2 (Z −14.2→80)
  - 레일 중심 X 간격 **101.4** (−129.27 / −28.37) — 젯슨(보드 폭 100)이 이 사이에 들어간다(PDF 5·7쪽)

## BOTTOM — 차체 아래 상자
- 외곽 **134 (X) × 116 (Z) × 53 (Y, 높이)**, 벽 3, 바닥 3
- 뒷벽(Z 115→118) 전높이, 앞벽(Z 2→5)은 높이 35까지
- 양 옆벽 창 **43 × 57** (배선/환기)
- 바닥 구멍 M3 Ø3.4:
  - 2개 (−104, 32) / (−36.5, 32) — STL 좌표차 67.5. ⚠ 2026-09-27 사용자 실측으로 **56.7**로 정정
    (SO-101 받침 전면쪽 구멍은 56.7을 쓴다 — STL 계산값이 아니라 실측이 맞다)
  - 4개 ×2조: X {−123.5, −97.5} × Z {49.5, 66.5} (26×17) · X {−38, −16} × Z {49.5, 66.5} (22×17)
  - 각 조 둘레 얕은 포켓(깊이 1.5) 44.5×17 / 38.8×17
- 앞벽 Ø6.0 구멍 2개, X 간격 105 (−121.6 / −16.6), 높이 16

## 이어서 정한 것 (2026-09-26)
- **배터리 4S3P = BOTTOM 관통 터널에 끝까지 들어가는 크기.** 터널 = 양 끝벽 창 **43(높이, Y 3→46) × 57(폭, Z 58→115)**,
  길이 134 전 구간 막힘 없음(STL 단면 확인). 18650 2×3×2 = 37×55.5×130과 맞는다 → 케이스 배터리 자리 43×57×134.
- **SO-101 받침 체결 4구멍 전수 실측 완료 (2026-09-27).** 받침 중심선(X=0) 좌우대칭, 회전판 좌표 +Y=전면:
  - 전면쪽 2개: 간격 **56.7**(← 이전에 BOTTOM STL 좌표차로 계산한 67.5는 폐기), 회전축보다 15.0 앞
  - 후면쪽 2개: 간격 **64.4**, 회전축보다 55.0 뒤
  - (2026-09-27 중간에 앞/뒤가 한 번 뒤바뀌어 정정됨 — 최종은 위 값)
- **차체 상판 도면은 공개된 것이 없다.** 제조사 GitHub([MoebiusTech/MecanumRobot-Arduino-Uno](https://github.com/MoebiusTech/MecanumRobot-Arduino-Uno))엔
  사진뿐인 설치 설명서 PDF만 있고, 쿠팡 페이지의 조립설명서 링크(naver.me/xFrOQ0yY → 네이버 MYBOX 공유폴더)는
  자바스크립트 페이지라 밖에서 목록을 못 읽는다 — 브라우저로 열어 파일을 받아 저장소에 두면 읽는다.
  (케이스는 체결 패턴 기준이라 상판 도면 없이도 된다.)
