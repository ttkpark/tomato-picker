잡기 판정 규약 (1차·3차 공통)

성공 = 닫은 뒤 집게 센서값 ≥ 6.0(빈손 5.0~5.4, 물림 6.2~6.9, 11/01 실측) 그리고 사람 눈으로 줄기가 두 손끝 사이에 있을 것. 화면에서는 맞았는데 안 물린 경우는 실패로 셉니다.

  • 매 회 토마토를 옮깁니다: 좌우 ±5cm, 앞뒤 ±3cm, 회전 ±20°를 주사위로 정함 (같은 자리 반복은 성적이 과장됩니다).
  • 실패는 넷 중 하나로 기록: 빈손 / 엉뚱한 곳(꼭지·고리) / 충돌(화분·지지대, 즉시 중단) / 60초 초과.
  • 20회는 하루에 끝내고, 중간에 코드를 고치면 처음부터 다시 셉니다.
  • 제출물: 표 1장(회·옮김·결과·실패종류·소요초·집게값) + 전체 영상 1개.

위험과 대응

  • 기판 납기: 11월 안에 주문하지 않으면 12/30을 못 맞춥니다. 그래서 0차에 주문을 넣었습니다. 12월 중순을 넘기면 2차를 1/15로 미루고 1주 전에 말씀드립니다.
  • 잡기 성공률이 50% 밑으로 떨어질 때: 실패 4종 분포를 먼저 보고, 가장 큰 통 하나만 고칩니다. 게인을 여러 개 동시에 만지지 않습니다.
  • 1인 개발: 체크포인트마다 "표 1개 + 영상 1개 + 다음 할 일 3개"만 보고합니다. 기한을 못 지키는 것보다 말 없이 밀리는 것을 막는 게 목적입니다.
