## 2. 하드웨어 구성 (v0.1 원문)

### MCU
- STM32 F4급 (예: STM32F405, STM32F411)
- 이유: 타이머 4개 하드웨어 쿼드러처 엔코더 + PWM 동시 운용 가능
- 동작 전압: 3.3V 로직 (젯슨 UART 직결 가능, 레벨시프터 불필요)

### 모터 드라이버 4채널
- 대상 모터: 브러시드 DC 기어모터 × 4 (메카넘 4륜)
- 추천 칩: DRV8833 또는 TB6612FNG (모터 정격전류 확인 후 확정)
- 채널: FL / FR / RL / RR 독립 제어
- PWM 주파수: 10~20kHz 권장 (가청 노이즈 제거)

### 엔코더 4채널
- 방식: 모터축 마그네틱(홀) 엔코더 (AS5048B 류 또는 모터 내장형으로 교체)
- STM32 연결: 타이머 쿼드러처 모드 (TIM1/TIM2/TIM3/TIM4)
- 용도: 바퀴별 속도 피드백 → PID 속도제어

### UART (젯슨 ↔ STM32)
- 속도: 115200 baud
- 젯슨 핀: 3.3V UART (레벨시프터 없이 직결. GND 공통 필수, TX↔RX 교차)
- 프로토콜 (기존 mecanum_stable 호환 유지): `V vx vy w` · `S` · `T i d` · `P n` · `L a b c d` · `?`
- STM32 내부에서 PID 수행 → 젯슨쪽 코드 수정 없이 호환

### E-stop (하드웨어)
- 버튼 → 컨택터(릴레이)로 모터 드라이버 전원 물리 차단
- STM32 GPIO로 E-stop 상태 감지 → UART로 젯슨에 보고
- 소프트 E-stop(PWM 0) 별도 보조 유지

### 배터리 전압 모니터링
- 분압저항 → STM32 ADC (예: R1=100kΩ, R2=10kΩ → 24V 배터리를 3.3V 이하로 환산)
- 주기적으로 읽어 UART로 젯슨에 전송
- 저전압 임계 시 STM32가 먼저 감속→정지 후 경고

## 3. 전원 설계 (v0.1 원문)

기존 실패 원인: 팔+모터 동시 기동 시 순간전류에 5V 레일 강하 → 아두이노 리셋

1. 로직 전원(3.3V)과 모터 전원 레일 완전 분리 — 로직: 별도 벅레귤레이터(LDO 아닌 스위칭), 모터: 배터리 직결 or 별도 레귤레이터
2. 모터 레일 벌크 커패시터: 1000~4700uF × 2~3개
3. 로직단 디커플링: 100nF 세라믹 × MCU 핀마다, 10uF 전해 × 레귤레이터 출력
4. STM32 BOR 레벨 2.7V 이상
5. 모터 전원과 젯슨 전원 소스 가급적 분리 (공통 GND만 유지)

## 5. 기존 대비 변경점 요약 (v0.1)

| 항목 | 기존 (아두이노 우노) | 신규 (STM32) |
|------|---------------------|-------------|
| MCU | ATmega328P (8bit) | STM32 F4 (32bit, 168MHz) |
| 모터 드라이버 | PCA9685(I2C)+내장 H브리지 | DRV8833/TB6612 직접 제어 |
| 엔코더 | 없음 (오픈루프) | 4채널 쿼드러처 → 속도 PID |
| 전원 | 로직·모터 혼용 (브라운아웃) | 레일 분리 + 벌크 커패시터 |
| 통신 | UART 115200 | UART 115200 (호환 유지) |
| E-stop | 없음 | 하드웨어 컨택터 + GPIO 감지 |
| 전압 모니터링 | 없음 | ADC + 저전압 자동 정지 |

## 6. v0.2 — 반영 결과

**표시**: ✅ 그대로 반영 · 🔁 같은 목적, 다른 수단(근거 있음) · ⏳ 실물 확인 필요

| v0.1 항목 | 반영 | 기판 / 펌웨어 |
|---|---|---|
| MCU F4급 | ✅ | **STM32F405RGT6**(LQFP-64). F411은 TIM8이 없어 PWM이 USART1 핀과 겹쳐 제외 |
| 엔코더 타이머 쿼드러처 ×4 | ✅ | TIM2·3·4·5 (TIM1/8은 PWM에 씀 — 4개면 번호는 무관). 5V 홀센서 → 1k 직렬 + 10k 풀업 → FT 핀 |
| 바퀴별 PID, 젯슨 수정 없이 | ✅ | `V`는 그대로, 바퀴별 `G i kv ks kp ki`(계약 §5.2)를 주면 그 바퀴가 폐루프. 기본 kv=0 = Uno와 같은 개루프. 엔코더 부호가 틀리면 폭주 감시가 그 바퀴를 개루프로 되돌림(`clfault i`) |
| PWM 10~20 kHz | ✅ | 기본 **20 kHz**(`F`로 24~40000). ⚠ 젯슨 `base_tuning`의 F 700을 20000으로 바꿀 것(코드 수정 아님, 설정값) |
| 드라이버 DRV8833 / TB6612 | 🔁 | **DRV8874** — DRV8833은 VM 10.8 V, TB6612는 15 V 한계라 지금 레일(최대 12.6 V)·24 V 가능성 둘 다에 여유가 없다. DRV8874는 37 V · 6 A 피크 · 전류 감지(IPROPI) · nFAULT · 내부 전류 제한(≈2.3 A로 설정) |
| 하드웨어 E-stop(릴레이로 모터 전원 차단) | ✅ | **K1 SRD-05VDC-SL-C**(10 A/28 VDC). J6 단자의 NC 버튼이 5 V → 코일 경로를 끊으면 접점이 **VM을 물리적으로 끊는다**(MCU 무관). 로직 전원은 릴레이 앞에서 따서 E-stop 중에도 MCU·링크는 산다. 버튼이 없으면 J6을 단락 |
| E-stop 감지 → 젯슨 보고 | ✅ | 코일 전압 → PB13. `estop 1/0` 이벤트 + hb `estop=`. 걸린 동안 `V` 무시, 풀려도 새 `V`가 올 때까지 정지 |
| 소프트 E-stop 보조 | ✅ | `S`·데드맨(300/1000 ms) 그대로 + nSLEEP |
| 배터리 분압 100k/10k | ✅ | R9/R10 = 100k/10k(÷11, 36 V까지) → PC4. hb `vin=`(mV) |
| 저전압 시 감속→정지 후 경고 | ✅ | `B ratio_x1000 lo_mv`(계약 §5.2). 기본 6.4 V(2S 3.2 V/셀), 2초 지속 시 `lowbat 1` + 슬루 감속 정지, +0.3 V 히스테리시스로 해제 |
| 3.3V 로직을 스위칭 벅으로 | 🔁 | 배터리 → (다이오드 + 470 µF 홀드업) → **5V 스위칭 벅 TPS542025** → 3.3V LDO. 배터리에서 3.3 V를 바로 리니어로 내리는 게 아니라 이미 안정된 5 V에서 1.7 V만 떨어뜨리므로(≈0.2 W) 명세 의도(모터 레일 붕괴와 분리)를 만족. 5 V는 엔코더 전원도 겸해 벅이 하나 더 필요 없음 |
| 모터 레일 벌크 1000 µF × 2~3 | ✅ | **1000 µF 35 V × 2**(C1, C14, 릴레이 앞 배터리 노드) + 드라이버마다 10 µF + 100 nF. 릴레이 뒤에 큰 전해를 두면 접점이 닫힐 때 돌입 전류로 접점이 붙을 수 있어 앞에 둠 |
| 디커플링 | ✅ | MCU VDD 핀마다 100 nF + 4.7 µF, VCAP 2.2 µF ×2, 레귤레이터 입출력 10~22 µF |
| BOR ≥ 2.7 V | ✅ | 첫 부팅에 옵션바이트 BOR Level 3(2.7 V) |
| 젯슨 3.3V UART 직결, GND 공통 | 🔁 | **J7 헤더(3.3 V UART)** 를 절연기(ADuM1201) **앞**에 붙였다 — 젯슨 TX/RX/3.3V/GND를 직결하되 젯슨 GND는 보드 쪽 절연 칸(GNDU)에만 닿는다. "GND 공통"은 통신 기준점이 필요해서인데, 그건 절연기 앞단이 해결하고, 모터 GND와 젯슨 GND를 실제로 잇는 것은 지금 USB 끊김(`error -71`)의 원인(접지 루프)이라 끊었다. 기본은 USB(Mini-B, CH340C → 젯슨 `/dev/ttyUSB0` 그대로). J7을 쓰려면 R62~R64(0 Ω)를 빼고 젯슨 포트를 `/dev/ttyTHS*`로 |
| 모터·젯슨 전원 분리 | ✅ | 위와 같음(절연으로 GND까지 분리) |

### 미확인 항목 처리

| v0.1 미확인 | v0.2 |
|---|---|
| 모터 엔코더 장착 가능 여부 | ⏳ 쉴드 회로도상 모터 커넥터가 6핀(`M− GND ENC_B ENC_A 5V M+`)이라 엔코더 내장 TT 모터로 보인다. 기판은 같은 6핀 순서(JST PH 2.0)로 받는다 — **실물 선 6가닥·피치 확인 필요**. 엔코더가 없으면 AS5048B(I²C 절대각, 주소 4개)를 J4 I²C 헤더로 받는 대안이 있으나 기판은 쿼드러처 우선 |
| 모터 정격 | ⏳ 드라이버를 넉넉히(6 A 피크) 잡고 전류 제한 2.3 A(VREF 분압)로 묶었다. 정격을 알면 R13/R14만 바꾼다 |
| 배터리 전압 | ⏳ 지금 레일 7.8 V(2026-10-22)로 설계 7.4~12.6 V. **24 V로 가면 바꿀 것**: TVS SMBJ15A → SMBJ24A, 470 µF 25 V → 35 V, 10 µF 25 V → 50 V. 분압(100k/10k)·DRV8874·TPS542025(30 V)·벌크(35 V)·릴레이(28 VDC)는 그대로 됨 |
| 폼팩터 | ⏳ 100 × 70 mm 2층, 고정구멍은 **Uno와 같은 자리**(지금 스탠드오프 재사용). 케이스 트레이에 들어가는지 실측 필요 |
