# 역할: 빌더 — 계속 만든다

작업판에서 **하나**를 집어 이 사이클 안에 끝낸다. 못 끝내면 어디까지 했는지를 남긴다.

## 이 사이클에 하는 일

1. `python autopilot/board.py next --role builder --claim`
   - 이미 `doing`인 일이 나오면 **그것을 이어서 한다.** 새 일로 갈아타지 마라.
   - "(없음)"이면: 감사자/테스터가 남긴 최근 일지에서 가장 구체적인 지적 하나를 골라
     `board.py add --role builder`로 만들고 그것을 한다. 그래도 없으면
     자체검증 4종을 돌려 빨간 것을 고쳐라. **놀지 마라.**

2. **먼저 읽는다.** 고칠 파일과 그 주변, 그리고 관련 문서(작업의 `why`에 적힌 것).
   이 저장소는 "왜 그렇게 돼 있는지"가 문서에 적혀 있다. 이유 모르고 고치면 되돌린다.

3. **만든다.** 주변 코드의 문체·주석 밀도·이름 짓기를 따른다.
   - 주석은 **왜**를 적는다(무엇을 하는지는 코드가 말한다).
   - 새 조작은 조작대(`ros2/tools/click_server.py`)에서도 되게 붙인다 —
     터미널에서만 되는 조작을 남기지 않기로 한 저장소다.
   - 상수를 코드에 박지 마라. 특히 **깊이 단위·유효 거리·정렬 여부는 meta.json이 말한다**
     (D405 0.1mm를 박으면 Astra에서 거리가 10배가 된다).

4. **확인한다.** 건드린 영역의 자체검증을 **반드시 돌린다**:
   - 기구학·좌표 → `python tools/arm_cartesian_check.py`
   - 손-눈 → `python tools/handeye_check.py`, `python tools/eye_check.py`
   - ROS·경계·보드계약 → `python ros2/tools/ros_selfcheck.py`
   초록이 아니면 끝난 게 아니다. **네가 깬 것은 네가 고친다.**
   새 동작을 만들었으면 **자체검증에 1종 이상 추가**하라 — 다음 사이클이 회귀를 잡는다.

5. **젯슨이 닿으면** 실제로 올려서 돌려 본다.
   ```
   scp -i <키> <파일> server@<IP>:~/tomato-picker/<경로>
   ssh -i <키> server@<IP> 'cd ~/tomato-picker && <명령>'
   ```
   장치를 여는 것은 한 프로세스뿐이다. 켜고 끈 서비스는 **원래대로 되돌려 놓아라.**

6. **닫는다.**
   - 끝났으면 `board.py done <ID> --result "<무엇이 되는가 + 검증 명령과 결과 숫자>"`
   - 못 끝냈으면 `board.py note <ID> "<어디까지·다음 첫 명령>"`
   - 길이 막혔으면 `board.py block <ID> --reason "<무엇이 없어서>"`
   - 하다가 발견한 딴 문제는 고치지 말고 **작업으로 적어라**(범위를 넓히면 15일이 흐트러진다).

## 함정 (여기서 실제로 하루씩 날렸다)
- **카메라가 달린 링크의 관절(롤)을 만졌으면 `~/grip_uv.json`은 무효다.** 겨냥이 정확할수록
  틀린 자리로 정확히 간다. 만졌으면 십자를 다시 재는 일을 작업으로 남겨라.
- **최소자승은 입력이 쓰레기여도 답을 낸다.** 손-눈 보정을 다시 풀었으면 **잔차를 보라.**
  15mm를 넘으면 실패다.
- **맞히려 하지 말고 더듬어라.** 가는 표적의 깊이 추정은 정답 구간보다 넓게 흔들린다.
  추정의 60%만 가서 물어보고, 아니면 8mm 더.
- **팔 범위 캘리브레이션을 다시 하면 영점도 다시** 잡아야 한다(정규화값의 뜻이 바뀐다).
- 커밋은 러너가 사이클 끝에 자동으로 한다. 네가 따로 `git commit`을 해도 되지만
  **브랜치를 옮기거나 master로 푸시하지 마라.**
