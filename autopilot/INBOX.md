# 사람이 하는 말 — 자동운전이 매 사이클 **맨 먼저** 읽는다

여기 쓴 줄은 다음 사이클의 프롬프트 맨 위에 붙는다. 역할이 무엇이든 자기 일보다
**먼저** 처리한다. 처리하면 `- [ ]`가 `- [x]`로 바뀌고 `→ 처리:` 한 줄이 붙는다.
(체크된 줄은 다음 사이클에 안 보인다. 기록으로 여기 남는다.)

쓰는 법 — 둘 중 아무거나:

```
python autopilot\say.py "면봉 말고 진짜 토마토로 시험해"
```
또는 이 파일 맨 아래에 `- [ ] 하고 싶은 말` 한 줄을 직접 적는다.

말투는 아무래도 좋다. 짧아도 된다. 예:
- `- [ ] 그 방향 아니다. 평행이동부터 잡아라`
- `- [ ] T9는 내가 오늘 못 잰다. 그거 없이 갈 수 있는 데까지`
- `- [ ] 젯슨 지금 내가 쓰는 중이니 실기 만지지 마`
- `- [ ] 오늘은 문서 말고 코드만`
